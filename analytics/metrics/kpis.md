# Key Performance Indicators (KPIs)

The OS tracks these primary metrics to determine content success and agent performance.

## Audience Engagement

- **Click-Through Rate (CTR)**: Target > 8% for new uploads.
- **Average View Duration (AVD)**: Target > 70% of video length.
- **Returning Viewers**: Target > 30% of total views.

## Production Efficiency

| Metric | Target | Description |
| :--- | :--- | :--- |
| **Ideation Time** | < 2 Hours | From trend scan to approved idea. |
| **Scripting Time** | < 4 Hours | From idea to final script. |
| **Prompt Accuracy** | > 90% | Percentage of images that require no re-generation. |
| **Publishing Lag** | < 24 Hours | From final edit to live on YouTube. |
