# Image Prompt Library

## Core Visual Grammar

All prompts should follow this structure:
`[Style] + [Subject] + [Action] + [Environment] + [Lighting/Atmosphere] + [Technical Specs]`

### Master Style String
> `3D stylized render, Pixar/DreamWorks aesthetic, vibrant colors, soft lighting, ultra-kid-friendly, high resolution, 8k, Octane render --ar 16:9`

## Category Templates

| Category | Subject Focus | Environment Focus |
| :--- | :--- | :--- |
| **Nature** | Rosie/Buzz, oversized insects | Glowing mushrooms, lush meadows |
| **Space** | Astro/Nova, bright suits | Swirling nebulae, colorful planets |
| **Social** | Sparky (Robot), children | Vibrant playgrounds, sandboxes |
| **Fantasy** | Talking animals, puppies | Rainbow bridges, candy-lands |

## Reusable Snippets

- **Wonder**: `...wide eyes, glowing with curiosity, sparkles in eyes...`
- **Action**: `...mid-hop, zipping quickly, floating in low-gravity...`
- **Atmosphere**: `...bright sunny day, golden hour glow, magical luminescence...`
