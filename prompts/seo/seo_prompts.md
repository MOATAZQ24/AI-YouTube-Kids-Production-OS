# SEO & Publishing Optimization Library

## Metadata Generation

### Title Generator
> `Act as a YouTube Kids SEO Expert. Create 5 viral titles for a video about [Topic]. Focus on curiosity and educational keywords. Use emojis sparingly.`
> **Example**: `Rosie Finds a Secret Garden! 🌸 Nature for Kids`

### Description Template
> `Write a kid-friendly description for [Title]. Include a summary of the educational goal, a list of characters, and 3-5 hashtags.`
> **Keywords to Include**: `Learning for kids`, `Preschool education`, `Fun stories`, `[Specific Topic]`.

## Thumbnail Strategy

### Visual Hook Prompt
> `Act as a Thumbnail Designer. Describe a high-CTR thumbnail for [Topic]. Focus on: 1. Close-up of [Character]'s expressive face. 2. High-contrast background. 3. One large, clear object related to the hook.`

### Text Overlay
- Use 1-3 words maximum.
- Font: Bold, rounded, bright yellow or white with black outline.
- Keywords: `WOW!`, `SECRET!`, `LOOK!`, `WHAT IS IT?`
